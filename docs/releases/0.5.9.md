# Mike 0.5.9 — a quieter heartbeat

- The service asks Mike's server for work less often. With no work in hand,
  one call per pulse says the computer is here and asks for the next task,
  instead of two calls (Heartbeat, then ClaimTask) every 2 seconds.
- The server sets the pace (my-euglena-apps ticket 352): every 2 seconds
  within 2 minutes of a task being handed out or finished, every 7 seconds
  when idle. A task Mike gives an idle computer reaches it within 7 seconds.
- Against an older server, which does not set the pace, the service asks
  every tick with a separate ClaimTask, as before.
