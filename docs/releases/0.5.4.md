# Mike 0.5.4 — Mike CLI starts on your conversations

- An interactive `mike-cli` now opens like Mike's pages: it shows this
  computer's five latest conversations; `/open N` continues one, typing
  starts a new one, `/conversations [all]` lists more. Nothing is shown when
  there are none, or when the service is older than 0.5.3.

- mike-service: a terminal step may run in `~` (or `~/folder`), this
  computer's home, so Mike no longer has to guess a home path such as
  `/home/mike`. The service says so with the `terminal_home_v1` capability.

- mike-service: Mike may run a `sudo <command>` step (no sudo options). It is
  always asked in Mike first, whatever the mode, and runs as `sudo -n`, so it
  needs a NOPASSWD sudoers rule on this computer (README, "sudo"); without
  one the step fails and says so. The service says so with the
  `terminal_sudo_v1` capability. The unit no longer sets `NoNewPrivileges`;
  every other step still runs with no_new_privs.
