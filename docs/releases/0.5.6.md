# Mike 0.5.6 — root steps through mike-root

- `mike-service install-root` (asks the sudo password once) installs
  `mike-root`, a root-owned helper, and a single sudoers line for it alone,
  with no arguments. A root step runs only with a step Mike's server signed
  after your Yes in Mike (always asked, even in Auto), for this computer,
  within two minutes, once. `mike-service uninstall-root` removes it all.
- The service offers `terminal_root_v1` only where mike-root and the server
  key are installed. Plain `sudo`, `su`, `pkexec` and `doas` steps never run;
  the 0.5.5 `sudo -n` path and its NOPASSWD advice are gone.
