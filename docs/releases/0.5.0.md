# Mike 0.5.0

Desktop is now a client of the separately installable shared local service.
The same service supports Desktop, the new terminal CLI and IDE's direct
connection, plus scoped headless remote work. Closing a client does not stop
the shared service. Existing pairing can migrate without exposing credentials.

This release contains three Linux x86_64 archives: mike-desktop, mike-service
and mike-cli. Use CDLVSM 0.12.0 or newer so declared dependencies, shared
service lifecycle and exact Code bindings are resolved. IDE 0.19.0 selects
Mike optionally with `cdlvsm install ide --with mike`; CLI is not required.

The service retains its verified Code >=2.12.1 <2.15.0 binding (pin 2.14.5).
It can coexist with Code 2.17.0 without replacing the user's active compiler.
Editor protocol 1 binds capabilities to the originating client and project;
IDE applies revision-checked edits and existing diff approval.

Central mike-api source must include the matching headless/editor protocol
changes. Publishing these local packages does not deploy the backend or
replace an installed/running service. Release dry runs verify the packages,
local service fixtures, Python tests and a real Desktop window smoke test.
