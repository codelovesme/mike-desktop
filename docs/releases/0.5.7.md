# Mike 0.5.7 — /compact in the terminal

- `/compact` in `mike-cli` summarizes the open conversation, the same as
  Mike's page: the messages stay saved, and later messages in that
  conversation go to the model as the summary instead of word for word, so
  long conversations answer faster. Before the first message it says there
  is nothing to compact yet; a refusal from Mike is shown as it came.
- The service adds `/v1/chat/compact` and advertises `compact` in its
  status, so an older service is told apart ("upgrade mike-service").
- `tools/cli-compact-e2e.py`: the real CLI, service and model against the
  disposable scratch stack (8 checks).
