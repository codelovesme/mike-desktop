# Mike 0.5.1

The shared service can hear: `POST /v1/chat/hear` hands a recording (WAV or
WebM, about a minute at most) to Mike's `Hear` with the service's own
account session and returns the words. Nothing is kept and nothing is asked
of Mike — the client shows the words first. IDE 0.21.0's voice input
(Ctrl+Shift+Space) uses it when the IDE is signed in to codelovesme.

It refuses a signed-out service (409 `signed_out`), an empty recording or
unknown format (400), a longer recording (413 `too_large`), and says when
Mike could not make it out (503 `mike_unavailable`). The local listener
takes request bodies up to 4 MiB. Nothing else changes: Desktop, CLI,
pairing and editor protocol 1 are as in 0.5.0, with the same Code binding
(>=2.12.1 <2.15.0, pin 2.14.5).
